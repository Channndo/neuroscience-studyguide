# Brain figure assets

Anatomy quiz figures are built in `brain-anatomy-diagrams.js`:

- **Midsagittal:** anterior left, posterior right, dorsal up (standard radiologic/schematic convention).
- **Lateral:** left hemisphere, rostral left, caudal right.
- **Coronal:** level of thalamus and basal ganglia (dorsal up).

The question pool lives in `questions-brain-anatomy.js` (50 items). To use licensed atlas photography later, add PNG/SVG files here and map regions in `BRAIN_ANATOMY_DIAGRAM.diagram()`.
